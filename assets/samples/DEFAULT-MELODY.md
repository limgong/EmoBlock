# 默认旋律：欢乐颂主题

- 原作：Ludwig van Beethoven，《欢乐颂》主题。
- 参考出处：[Mutopia 528](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=528)，页面标注 Public Domain，谱例维护者 Peter Chubb，版本 Mutopia-2009/08/05-528。核查日期：2026-09-24。
- 本项目内置的是自行编码的前 8 小节单声部主题，移至 C 大调、4/4 拍；不是下载的商业录音，也没有复制四声部伴奏。用于演示主题、变体和连接；不得将该主题宣称为本项目原创。
- `default_melody.py` 仍保留桌面默认旋律规则。`ode-to-joy-theme.mid` 于 2026-10-09 更新为古典单旋律素材包的最新版：30 个音符、32 拍、110 BPM，音符按 LMMS 网格对齐。Demo 工程沿用固定 120 BPM，原素材 BPM 记录在来源信息中。文件校验和与其他古典素材的署名见 `classical-catalog.json`。
- 新建简要 Demo 自动载入，与默认 13 格情绪故事配合，可以直接生成。首次导入用户旋律时替换默认素材，后续继续追加；打开已有工程不替换其素材。
