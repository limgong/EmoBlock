## 已实施

1. 来源栏开关改为固定顶部的侧栏线条图标，保留会话选择、筛选、滚动和当前播放状态。
2. 素材只呈现块和组合；原始整句父卡隐藏，重复原始句切片不占可见编号。生成乐句及 Bridge 保留后台整句身份，在素材区逐块展示分组信息，逐块拖拽。
3. 名称持久保存于现有 label/label_counters：原始 A、新旋律 B、入库 Bridge C；手动派生 A1′、A1′(2)、A1′′；组合 A1+A2。内部身份仍为 ID，编号不依赖当前筛选顺序。
4. 新旋律方法进入右键/Control-click/Shift-F10 菜单，绑定实际目标 ID。明确执行才生成，失败如实显示。顶部生成下拉与组合草稿栏不再显示。
5. 保留左右拖放次序和拖影，松开后简单确认自动组合名与拍数。取消无工程写入，确认后一次撤销可恢复；组合与重复使用保留来源快照。
6. 共用播放器主行是圆形播放/暂停、停止、实际 PCM 波形和 mm:ss。当前 A 播放时选择 B 不抢播；明确 B 试听才切换。自然结束后没有新选择时重播原对象。版本、导航、导出和取消位于紧凑次级行；详细时长进入详情。
7. 空缺显示短标签及虚线范围；编排模式可直接选空缺，范围/返回全部及主动留白入口可见。普通入口生成完整候选，后台仍执行补全→Bridge位置保护→Bridge生成→连接块→块间连接→编配、校验与渲染。
8. 候选短名为方案1/方案2。差异摘要读取真实音高和节奏；相同旋律不伪称不同。明确试听处理后完整效果，采用复用原有认证快照路径，一次撤销恢复。
9. 详情、高级工具和导出回执使用原生、有边界、内部可滚动的上下文区域；播放器不再因导出回执增高。按真实可用高度保留画布≥320逻辑像素。补全取消后在布局稳定后恢复进入前的滚动书签。

## 打开新 UI

在本轮 `ui-mainline-20261008` worktree 中双击 `launch_current_ui.command`，或运行 `run.py`，使用已有 Python 3.11 虚拟环境；建议用独立 `EMOBLOCKS_DATA_DIR`，避免与运行中的旧窗口共享生成缓存。窗口导入仓库 `assets/samples/ode-to-joy-theme.mid` 可检查真实 MIDI 分块。
