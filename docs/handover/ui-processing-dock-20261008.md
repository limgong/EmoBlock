# UI 交付：积木质感与画板下方工作区

基线：`64c78b556ff66fcd038b28c492e47ec4e9546d6c`。开发分支：`codex/ui-mainline-20261008`。

## 界面与交互

五个区域为旋律原料、音乐积木库、情绪搭建画板、智能加工、调校成曲。八步名称只用于介绍，音乐计算顺序仍为补齐、Bridge位置确定与保护、Bridge生成、连接块、块间处理、编配渲染。

原始分块显示“原素材·原料N”，来源编号取自工程保存的来源顺序，不受筛选影响；文件名和来源路径在提示及详情中查看。生成素材、生成乐句的子块和组合不会误标为原素材。

组合使用当前主题的应用内确认窗口，只显示自动名称、拍数、组合和取消。关闭与Esc取消，确认沿用原有原子事务，不生成额外试听。

浅色使用蓝白Soft UI。暗色保留静态三级深灰。积木用圆角、纯色明暗边缘表现块体感；浅色轻阴影，暗色克制阴影及1px外框。编号、情绪和旋律线保持在块体内，短块可使用外部编号提示；记忆、保护与选择使用不同标记。

拖动时保留原位置虚线占位，同一外观的积木随鼠标移动，并保持抓取偏移。落位轮廓显示拍吸附与合法性。释放才提交，Esc或非法落点取消。垂直拖动不改变强度线，移动、删除不压缩时间轴。普通点击释放后才展开详情，避免按下时打开面板遮住拖动落点。

详情、高级、方案共用一个画板下方的展开面板。同一时间只显示一种内容，播放器保持可见。面板最高220逻辑像素，展开后可见画板至少240，收起后至少320；场景至少400逻辑像素，面板展开不压缩曲线。画板和面板各自拥有滚动区域，遮挡处不能点击穿透。

鼠标滚轮优先滚动画板的纵向溢出；Shift滚轮横向滚动，无纵向溢出时沿用横向滚动。触控板分别处理两个轴，拖动近边缘可双轴滚动。候选视图的返回书签包含横纵位置。

收起面板或按Esc收起面板不退出候选，不取消计算、不应用方案、不改变播放对象；“返回编辑”是明确退出候选的操作。选中积木后情绪选项在详情中，选中空缺后处理入口在方案中。控件说明使用提示，错误与关键状态仍显示在固定状态行。

## Mac人工验收

从当前分支目录启动 `launch_current_ui.command`，或使用现有Python环境执行 `run.py`。入口默认使用隔离的主线UI数据目录。建议关闭自己不再需要的旧版窗口，以免查看错误版本。

1. 导入仓库样例 `assets/samples/ode-to-joy-theme.mid`，确认分块来源标签；再导入另一首，检查“原料2”及筛选后编号稳定。
2. 右键拓展一个积木，检查新旋律不标为原素材，仍保留来源。拖到另一卡片左右侧组合，分别取消、关闭和确认，核对顺序与一次撤销。
3. 在1020×700和更大窗口分别切换两种主题，检查五区标题、图标、颜色与播放器。检查原料栏收起后仍可恢复。
4. 绘制强度线；拖入和移动短块、普通块及组合，确认本体跟随鼠标、落位吸附和旋律线没有溢出。测试Esc、越界和重叠拒绝，以及移动后一次撤销。选中积木后分别实测Mac delete/Backspace和fn+delete，确认只删除一次且可撤销；输入框内删除不得删除积木。
5. 点击积木展开详情，切换情绪；在其他素材和记忆标记上移动鼠标，确认持久详情不被临时说明覆盖。
6. 切换详情、高级、方案：一次只出现一个面板。测试画板纵向滚动、横向手势、斜向手势、Shift滚轮以及拖动到边缘。覆盖区不能操作下方积木，播放器始终可点击。
7. 选中空缺生成方案，核对处理范围、两套真实音乐差异、试听与应用分离。收起面板后再打开，确认候选与播放保留；返回编辑检查选择与横纵位置恢复。
8. 实际试听时确认播放/暂停共用一个按钮，停止与取消容易区分。保存重开当前工程、导出所选版本，核对内容和播放对象。LMMS渲染及人工听感单独记录。
