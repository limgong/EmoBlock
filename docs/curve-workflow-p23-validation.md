## 约5分钟Mac人工验收

1. 0–1分钟：用现有环境启动run.py，新建空工程；导入仓库theme-c.mid。左栏整体来源、中栏分块/句与最多三种候选、右栏唯一画布。点击卡片应只选择；准备后明确播放，来源折叠不丢编辑。
2. 1–2分钟：拖同一分块到第1拍与第5拍，检查重复独立使用、占时宽度和每拍吸附。拖到重叠或越界应拒绝；移动/删除不压缩时间轴。拖卡片到另一卡左/右形成草稿，先取消再确认；原件保留，嵌套组合仍一外框。
3. 2–3分钟：控制点拖出强度峰值，再切手绘画峰谷；拖动中按Esc应完整取消，释放一次撤销可恢复。选择块点hope/sad/hope，不应累计失真；移动峰值观察记忆四拍落位，空缺显示待落位。素材拖动不搬强度线。
4. 3–4分钟：保存快照、修改、撤销回保存内容，检查保存状态；重开恢复精确放置、情绪与强度。试听不同素材/组合，确认播放器显示对象，选择不播放。听仓库外三套真实样例，比较原始、新旋律与情绪结果；单独记录主观质量。
5. 4–5分钟：浅/深主题及1020×700、更大窗口缩放，检查画布命中、材料首末滚动、情绪按钮、播放器和详情；截图做视觉验收。打开有历史输出的旧工程，应只读且WAV/MIDI/MMP按各自可用性导出，文件夹入口正确。整曲生成当前未接通，不应出现假成功。

Windows需实机补验：三尺寸与125%/150%系统缩放的字体/点击区域；鼠标滚轮及触控板、Esc/Delete与焦点；拖入/文件导入中文长路径；当前音频设备播放/暂停/停止；逐格式导出覆盖确认及打开文件夹。Mac和Windows都需第三方软件打开MIDI/MMP，不用字节一致代替可编辑性或音色一致验收。
