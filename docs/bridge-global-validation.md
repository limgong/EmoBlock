## 契约与实际问题

原实现可遍历全曲，但时间顺序搜索的固定反例在 128 次预算内只评估
0–480 tick 起点。相反方向的强度线得到相同的 max-min 趋势。旧 DP 固定
反例会选择 B+C=.75，而 A+C=1.0。这些复现记录分别为
`old-search-bias-reproduction.json`、`old-intensity-trend-reproduction.json`、
`old-dp-reproduction.json`；不是听感判断。

契约第 1 轮发现固定样例算术错误；第 2 轮修正为 16 点公式的
CS=161/192，并获独立 PASS，原契约随后冻结并保留。
首次实施发现跨使用实例计算 contour_turn 会错误切开必测乐句；
增量契约第 3 轮独立 PASS 后冻结为 global2，仅限定转折证据在同一
terminal/performance 内计算。分析版本为 v1.1，全曲动机关系仍跨乐句、
跨使用实例分析。两份冻结文档、历轮收据及失败复现均保留。

## 功能与门禁

新请求分析已验证的候选实际音符、情绪结果与接受覆盖层。组合叶组件和
重复使用各有真实时间归属；接受谱沿原 performance_map 解析，不从旧放置
或素材名猜测。实际休止、起音、节奏、转折及来源提示共同形成软乐句边界；
四拍线不是自动乐句边界。所有合资格乐句对比较重复、变化、回应与回归。
强度使用有符号发展、峰谷及真实情绪变化。

全曲特征实际进入预测收益，计入主题保留、重复发展、回归铺垫、强度方向
及切句代价。该收益是规则预测，不是生成后质量比较或准确率。
先覆盖主要时间区域与句界，再细化候选；记录全集、已评估与未评估范围、
停止原因及 DP 选择。预算不足不会称为全曲确定无需 Bridge，更不宣称
音乐全局最优。合法 none、无可写空间、预算不足、取消及错误分开。

低层旧请求默认 v1；当前 Controller 与完整推荐明确走 global-v2。
旧事务测试显式保留 v1，旧两字段 search 不升级。新分析、队列、实际评价、
选择及覆盖须通过纯数据认证，不能仅用重算指纹接受伪造事实。
保存、打开和撤销不调用分析入口、选位或作曲来修复旧记录。

位置与全部范围锁仍在同一事务登记；音乐生成继续使用原 v1，
Bridge 全集真实 READY 后才可进入连接和最终边界。生成失败、取消及
过期请求保留审计及保护，撤销到相同内容不会恢复旧授权。
不放宽记忆跨界音符、手工/主题保护、主动留白、来源及固定总长。
