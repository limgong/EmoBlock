## 后端暂存与门禁

- 真实空缺是放置/主动留白之外的精确tick补集，ID绑定原Project指纹；选中只处理完整目标，旧坐标与半目标拒绝。
- CompletionRequest捕获原版本Project、实际左右音符、完整来源和保护；计算私有Project为p4，当前旧工程仅打开、查询、计算、保存不迁移。
- 新素材、情绪和正式P3记忆只进入私有候选；旧放置的全部基础快照、实际变体与参数保持不变。名义保护、全长跨界音符支撑、旧手工保护、桥失败锁不能被删除或放宽。
- 完成门禁独立重建候选：每目标由实际素材完整覆盖，每独立新放置非empty，每目标有有效发声；对派生字段、来源、保护、指纹与post音乐差异重新验证。不授予最终应用、试听或整曲导出资格。
- Attempt与输入Snapshot独立持久化，READY只代表基础候选。取消消费完整token；迟到/重复不回写。有效编辑、undo/redo使旧READY/RUNNING持久STALE，撤回同内容不复活。RUNNING重开INTERRUPTED，不恢复后台线程。
- 音乐is_saved与staging_dirty分别显示/保存；候选计算不增加撤销或消耗显示编号。暂存未保存时自动保存保护同样有效，失败停止新建/打开/关闭。

## 待验与五分钟Mac流程

1. 新建空工程，导入旋律，逐块放置并主动留一处短空缺；点击素材仅选择，明确播放才试听。
2. 进入空缺选择模式选一个实际空缺，计算基础候选；确认进度来自真实阶段，计算时可取消，旧播放器不被抢占。
3. 查看两套基础排布、实际情绪/警告与剩余空缺；明确尚未处理bridge与连接，没有最终确认应用、候选整曲试听或导出入口。
4. 返回编辑，改变强度或放置，再undo回原内容；旧候选仍失效。取消/重试保留编辑、保存状态和撤销历史。
5. 保存快照后重开，检查原编排、强度、保护与暂存候选；运行中保存的任务重开为已中断。确认素材共用播放器与旧成品WAV/MIDI/MMP逐格式导出仍可用。

人工鼠标/触控板、双主题视觉截图、人工听感、Windows字体/滚轮/快捷键/播放器与125%/150%缩放待实机验收。原生背景模糊未实现；情绪数据色为已授权例外。
