## Mac最短复核

1. 以已有环境启动公开入口run.py；打开本轮ready工程副本或导入清单里的MIDI/MMP。检查点击只选择，明确播放才播放，所有对象共用右栏底部播放器。
2. 选片段拖入单一强度画布；横/纵滚动后移动、删除，检查Backspace/Delete、Command撤销/重做和Esc取消。左右拖入素材卡形成组合草稿；取消不新增，确认保留原素材。
3. 手绘强度并结束，单次撤销恢复；点击积木改情绪，移动不带走曲线。查看bridge、连接与记忆不同标记；记忆不增加时长。
4. “查看建议”与“自动补全”分别执行：全部空缺与一个选中空缺。局部方案保留其他空缺、正式导出禁用；完整方案明确阶段直到音频就绪。取消/失败后仍可编辑，点击候选不抢播。
5. 明确播放基础与处理后，切换仅主旋律/完整编配，检查对象和模式；暂停/恢复/停止/重播。确认后一次撤销/重做、保存新快照重开、选择接受历史版本导出三格式；声音与确认谱一致，不重新随机。
6. 浅/深主题、1020×700/1280×800/1440×900，来源展开/折叠；检查长名称、多素材、忙碌/错误/焦点/禁用和原生下拉。真实截图记录窗口尺寸，勿用Canvas导出。

以上是功能/视觉步骤；实物鼠标/双指触控板、人工听感必须另外记录。固定1秒尾音不保证适合所有素材。主题为静态Vibrancy风格，真实背景模糊未实现，情绪数据色为已确认例外。

## Windows partner本地步骤

不自动发送或上传。取得本地交接清单后逐文件核对SHA256；用现有已安装Python/Tk/LMMS，不安装大型软件或复制LMMS二进制。设置隔离data目录，记录自身版本与目标资源路径。

1. 先100%缩放，使用上述公开工作流；再125%和150%检查三尺寸、中文、菜单、焦点及按钮可达。
2. 鼠标滚轮/横滚、左右组合、拖入/移动/Delete、Esc取消、Ctrl撤销/重做；输入框焦点下不能误删作品。
3. 当前实际设备播放/暂停/恢复/停止/重播/切换；记录通道/采样率及错误，不改变默认设备来凑通过。
4. 中文、空格和长路径保存重开/三格式导出；在目标LMMS实际打开MMP，核对音符/时间及全部外部资源解析。Mac绝对资源路径不可解析要FAIL并记录，不能放宽认证或称自包含。
5. 实际可用MIDI/WAV软件打开，记录软件版本、音符/速度/时间；不同软件音色不同不等于结构错误。
