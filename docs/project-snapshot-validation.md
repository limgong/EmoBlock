## 保存语义

沿用 `emoblocks.studio.v1` 和旧结构/素材池工程读取能力。每次保存创建独立 JSON 快照，独占创建，不覆盖历史文件。先完成序列化，再写入、刷新与同步文件；失败只清理本次新建的不完整文件，旧快照不动。

顶栏分别显示“工程已保存/工程未保存/新工程尚未保存”，底部保留编辑与最新成品的一致性提示。保存状态比较实际持久化字段（素材、情绪线、参数、成品元数据），不包含选择、试听、滚动、悬停及临时缓存。撤销回已保存内容恢复已保存；生成新增成品会使工程未保存，保存本身不生成音频。

“保存快照”成功提示时间、缩略文件名和位置；悬停与“位置”查看完整路径，位置窗口支持复制并可打开所在文件夹。新建后仍可查看前一工程最近自动保存的位置，并明确其不属于当前新工程。

打开先读取与验证，再按需保存当前内容；恢复中途失败回滚当前数据、成品列表和撤销/重做历史。取消打开不停止播放。保存失败阻止打开、新建和关闭。成功切换清空编辑历史与生成反馈，停止旧播放。缺失原导入文件时使用已有音符快照；缺失历史音频时保留版本并标为不可用，只禁用缺失文件对应的操作。
