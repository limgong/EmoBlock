# 三栏工作区人工复核

只使用本轮隔离工程副本、音频及导出目录，不改真实工程。记录HEAD、平台/Python/Tk/LMMS、窗口尺寸/缩放与设备。P8旧音乐对照仍可引用，但保留旧执行版本。

1. MIDI/MMP导入后画布保持空；查看短尾拍数、稳定编号和来源详情。选择来源只筛素材，卡片只选择；明确“试听”自动准备后播，所有对象共用右底播放器。
2. 设置总格数，控制点/手绘编辑；拖入转编排。移动不带曲线，删除不压时间；重叠、越界或缩短截断拒绝。手绘Esc取消、结束一次撤销。
3. 左右拖到卡片形成组合草稿，取消无工程变化，确认保原素材。选择积木才有情绪，对该次使用重算；查看记忆、主动留白与bridge不同范围标记，组合子片段保护正确。
4. 全部、选中一个空缺和无空缺排列分别“生成方案”。阶段依次补全、桥立即保护和就绪、连接、最终边界、编配渲染；选择候选不播/不采用。局部余空缺保留并禁止正式输出。
5. 原始/处理后明确对比试听，切换仅主旋律/完整编配；停止/换选后旧准备不得抢播。暂停/继续/停止/重播，记录杂音或尾音具体秒数。
6. 返回编辑不采用，高级分阶段/手工bridge视图往返不丢草稿；次级“自动补全并应用”语义独立。采用一次undo完整恢复、redo同谱；保存新快照重开，历史版本和三格式导出一致，打开文件夹正确。
7. 两主题×1020×700/1280×800/1440×900×来源展开收起；小窗默认收起后手工展开不与自动布局争抢。编辑/审阅画布>=320px、右底player可达，hover与键盘焦点说明/长名全文有效。
8. Mac实体触控板双指/鼠标滚轮，滚动后拖入/控制点命中，Backspace/Delete/Command undo-redo/Esc和原生下拉；Windows100/125/150%对应Ctrl/Delete、中文字体/导出路径/LMMS工厂资源。未执行保持NOT_TESTED，不改变系统默认设备或安装新软件。
