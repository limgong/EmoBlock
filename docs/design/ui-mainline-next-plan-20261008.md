# EmoBlocks 主线 UI 后续计划

日期：2026-10-08。状态：已按确认规格实现主线 UI，测试及实机证据见 docs/handover/ui-mainline-implementation-20261008.md。以 Windows 主线验证候选的 Herdr R8 代码为起点，由接收方 Codex 当前聊天负责。Herdr 的职责为额外功能隔离开发、验收和交付。

## 工作流与视觉约定

保留三栏、唯一二维强度画布和底部共用播放器。明亮主题 Soft UI，黑暗主题静态 macOS Vibrancy：三级深灰、1px 边框、克制的交互反馈。保留素材和情绪数据色、真实旋律缩略图、拖拽反馈及自动隐藏滚动条。播放器圆形主控是用户参考图指定的局部造型例外。无需更换 Python/Tk 技术栈或实现原生毛玻璃。

先关闭当前基线的画布高度与键盘验证阻塞，再按以下阶段实施。每阶段记录代码提交与测试证据，旧 UI R1–R8 结论保持原记录。

## P1 来源栏与素材

- 来源栏开关采用参考图的侧栏细线图标和圆角方形底座，固定在顶部，隐藏后仍可访问；直接展开/收起，保存来源选择与滚动位置。窄窗口默认收起，用户手动选择在会话内优先。
- 素材区不展示完整原曲或整句父卡。原始素材显示标准四拍块，末尾保留实际长度；隐藏重复的原始整句分块入口。
- 生成的整句和 Bridge 展示内部块和简短分组标题，只允许逐块拖动，不提供整组拖柄。后台完整来源和乐句身份仍保留；自动连接过程中已经锁定的 Bridge 仍整体保护。
- 手动组合保留独立等尺寸卡片。常驻内容只保留短名、拍数、旋律图和试听图标；方法与完整来源进入提示或详情。
- 同类共用字母：原始块 A1/A2；无单一可见父块的新旋律 B1/B2；已入库 Bridge 内部块 C1/C2。手动派生与组合命名优先于类别编号。
- 从 A1 生成叫 A1′，再次生成叫 A1′(2)；从 A1′ 继续生成叫 A1′′。组合叫 A1+A2。编号不随筛选、排序、保存重开改变；内部身份使用 ID，不依赖名称。
- 移除顶部方法下拉框和新旋律按钮；右键块时提供生成新旋律子菜单，绑定该块 ID 与明确方法。支持 Mac 双指右击、Control-click、Windows 右击及键盘入口；右击只打开菜单，不播放或生成。
- 生成结果加入库并定位，失败显示原因，未接入方法不伪装可用。

## P2 简化组合

- 拖到卡片左侧放在前，右侧放在后；松开时弹出简单确认框，如“合并为 A1+A2？8拍”。
- 删除顶部组合草稿、命名输入和草稿试听。确认新增组合，取消/Esc/关闭弹窗不改变工程；原素材保留。
- 支持同素材重复使用与嵌套组合，一次确认对应一次撤销。确认后的组合仍可正常试听。

## P3 共用播放器

主操作行：播放/暂停、停止、真实波形、mm:ss / mm:ss；按参考图使用圆形播放和停止主控。

- 主按钮在播放时暂停、暂停时继续当前音频；空闲时播放明确选中的对象，结束且无新选择时可重播上一对象。
- 播放 A 时选择 B 不抢播；主按钮控制当前 A，明确点击 B 的试听才切换。
- 停止关闭当前播放和待执行的试听意图，不误取消其他音乐任务。
- 波形使用认证过的真实音频，显示实际进度并可定位。当前播放对象一行显示；版本、导出、块导航使用紧凑次级操作行。
- 所有对象共用底部播放器；模式、资产、快照、导航与导出对象不能串用。长名和正文/尾音时长进入详情。

## P4 补全与画布

普通流程：选择空缺 → 生成完整候选 → 对比试听 → 采用方案。

- 空缺使用浅底、虚线和“空缺·4拍”短标签；主动留白另用文字标识。編排模式点击选空缺，控制点/手绘模式优先执行相应编辑。
- 常驻范围显示“全部空缺·3处”或“当前空缺·4拍”；提供返回全部范围和设为留白入口。没有空缺时主入口为生成成品。
- 普通用户不逐步操作基础补全、Bridge 和连接。显示“补全→连接→试听准备”实际阶段及取消，不使用虚假百分比。
- 后端顺序固定：补全候选 → Bridge位置判断与保护 → Bridge生成 → 连接块判断及生成 → 块间连接 → 编配、校验与渲染。
- 候选以方案1/方案2切换，真实音乐差异用一行解释。在原画布只读预览，标识补入、Bridge与连接；点击候选不播放、不写工程。
- 默认明确试听处理后的完整效果；基础拼接对比为次级操作。采用应用已确认快照，一次撤销恢复，不重新随机生成。
- 返回编辑恢复选择与滚动位置。失败、取消、过期、不足两套有效结果或局部剩余空缺均直接说明，不伪造可用状态。
- 方案比较与详情共用有限高度上下文区，长详情内部滚动；1020×700，来源收起后，无论详情/候选是否打开，画布可见高度至少320px，关键按钮不遮挡画布。

## 接口与验收

短名解析统一覆盖素材、拖影、画布和播放器；新名称与计数用现有 label/label_counters 保存，旧 M数字兼容显示，不批量改写冻结快照或历史。右键生成明确传入素材 ID/方法；组合传入确认后的有序快照和自动名称。复用既有完整推荐及资产认证，不降低保护、时间或快照约束。

共享代码放 frontend/shared，同时检查两端适配器。运行配对检查和完整测试，核对两主题、最小窗口、多次导入/派生/组合、撤销保存重开、右键键盘、播放对象切换、全局/局部补全、留白、过期结果及试听快照应用。真实 Mac/Windows 输入、音频设备、LMMS 和人工听感单独记录。
