# EmoBlocks 简要创作实现计划

## 目标与边界

一个窗口内完成：旋律或短灵感输入 → 整块吸附且连续填满的情绪线与记忆点 → 自动发展素材、排布并替换连接 → 连续音频 → 修改、保存和恢复。保留原快速流程与精细模式。以工作流和约束正确为完成标准，不以音乐质量评价作为前置条件。

情绪线统一指“情绪种类 + 程度曲线”。用户绘制后自动整块吸附，整曲无未分配空隙；未绘制部分沿用已有情绪，初始为平静。连接是系统在已有时长内替换的音乐内容，不是用户留出的情绪空白。固定时间锚点优先；冲突报错，不暗中移动锚点。首版为离线、规则驱动，不接入付费模型、不实现游戏运行时重规划、不实现 WAV 主旋律提取。

## 实施顺序

1. 短素材引擎：输入 MIDI/MMP 音轨快照，主题角色推断，内容变体、回答与副旋律，保留素材血缘和顺序。
2. 时间规划：固定 4 拍音乐块（4/4 拍一小节），按 BPM 换算秒数；情绪区间自动吸附、无缝覆盖。固定秒数锚点和结尾仅局部截段，不均分或拉伸其他块。
3. 连接与编配：小落差末尾调整，大落差自动替换既有时间内的块；时间足够时生成多块 Bridge，不要求情绪留白，统一渲染 MIDI/MMP/WAV。
4. 单窗口交互：新增简要创作页，导入、区间与锚点设置、生成、块选择修改、情绪区间拖动、撤销。
5. 工程整合：共用保存、结果历史、播放高亮与导出；旧结构编辑器保留原有格式，不将短块伪装为旧式 4–8 小节素材。
6. 验证：短灵感、多主题、留白、锚点冲突、过渡预算、保存恢复、界面及实际音频渲染；运行旧测试防止回归。

## 技术选择

Python/Tkinter；mido、NumPy；复用已有 LMMS 无窗口渲染及音频处理。新规划器使用独立短块模型，避免破坏旧引擎的整数小节假设；以同一个工作台工程保存两类编辑状态。素材和情绪判断为透明规则，并不宣称已部署生成式 AI。

## 当前实现细则

### 目标

只需给出旋律即可生成；情绪区间和固定记忆点可选。加入副旋律、回答句和内容变体，再赋予情绪并衔接，不要求用户手工制作所有情绪版本。

### 选择原因（概述）

以硬锚点时间为优先约束，在既定总时长中预留连接预算，避免旧“插入过门后全部顺延”的机制破坏记忆点。旧模式沿用原机制，不混淆两个时间模型。

### 表达方式

1. 输入 1–12 段 MIDI/MMP，选择音轨；可选指定主基调、副旋律、爆点或结尾用途。短至单音动机也可输入；多声部同时起音需明确选择高音/低音或报错，不默默猜测。
2. 默认 48 秒，可设 4–480 秒，速度 40–220 BPM。选择情绪、强度和趋势后绘制区间；自动吸附整块并连续覆盖，数值编辑保留在精确设置。
3. 按需添加“时间 + 情绪 + 程度 + 保持时长 + 可选旋律”的硬锚点；锚点之间不能重叠。锚点高于普通情绪区间。
4. 预览排布或生成连续成品。拖动情绪区间色条改变时间位置；选择生成块可改情绪/程度/旋律，再生成新版本。固定块需修改锚点本身。
5. 保存工程后恢复全部音符快照与要求，不依赖原输入文件；生成结果保存当时的计划、编配、MIDI/MMP/WAV 和锚点误差报告。

### 实现手段

- 素材发展：短动机重复补足；后半句调内邻音变体、轮廓反向回答、调内移位及短奏副旋律。保留来源 ID、版本、乐句顺序和使用范围；角色参考密度、音域与用户指定，不把第一条输入直接当主基调。
- 切块：休止与长度用于乐句分组和来源记录；操作块固定 4 拍，不因慢速超过 4 秒而再次拆分，也不向起音挪动拍网格。固定秒数锚点与尾部不足一小节时局部截段并报告，不宣称已实现专业乐句识别。
- 排布：同源内容顺序延续，完成后可采用变体/回答/副旋律。明确主题选择和锚点允许中断。内容变体与情绪参数分开存储。
- 连接：根据前后程度/类别差及区间内强度发展计算替换预算。小落差末拍伴奏导向，中等预算 4 拍，大落差预算 16 拍；可用长度至少 8 拍时允许多块 Bridge。先保留旋律片段，再按真实末音/目标首音生成连接；遵循情绪线，不要求留白、不增加总时长。预算不足保留锚点并记录降级。
- 表达：音色交接、力度插值、基于当前旋律的调内和弦、低音、琶音/节奏密度、强情绪鼓组；一份总谱连续渲染。
- 时间：统一固定速度，采用 LMMS 48 ticks/拍网格，锚点量化误差最多半格（40 BPM 时约 15.6ms），报告请求和实际位置；并非采样级精准同步。作品正文外额外保留 1 秒尾音。

## 已知边界与后续

- 当前是规则工作流，不是训练好的情绪模型；不评价副旋律、调性判断与听感质量。
- 新简要模型与旧精细结构同工程保存、共用结果，但短块不能直接交给旧 4–8 小节编辑器；简要块在本页改，旧结构在旧页改。
- 简要模式修改后重新规划/渲染整曲；不承诺旧模式“范围外音符完全不变”的局部重编保证。
- 支持拖动情绪区间，不支持自由拖动或打乱所有音乐块。锚点目前通过删除再添加修改。生成音轨使用自带合成音色。
- 后续可增强：生成模型替换、专业乐句切分、DAW 接口、游戏实时事件重规划、WAV 提取、跨模式统一短块精细编辑；本轮不作为未完成项。
