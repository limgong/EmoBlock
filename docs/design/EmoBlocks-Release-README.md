# EmoBlocks — Windows 免安装版 · 2026-09-26 UI 更新

完整解压到可写、尽量短的路径（例如 D:\EmoBlocks），双击 EmoBlocks.exe。
不要从 ZIP 内启动，不要只复制 exe；app、_internal、runtime 文件夹必须一起保留。
Windows 64 位版本，无需另装 Python、LMMS、GPU 或服务器。

## 快速体验

1. 默认进入“快速成品”，内置《欢乐颂》和 13 块情绪故事，可直接生成。
2. 导入或拖入 MIDI / 未压缩 MMP。点击素材卡片试听，“分块试听”展开原旋律四拍片段。
3. 在情绪积木区拖动整段调整顺序，拖动接缝改长度；拖动到边缘可自动滚动。
4. 点击情绪颜色后，在积木区左键涂色；再次点击同一颜色，退出涂色并恢复拖拽。
5. 强度区圆点可上下拖动。记忆点自动位于强度最高处，同高时取最早处，随编辑更新。
6. 默认 B 浅色主题，月亮按钮切换 A 深色主题，太阳按钮切回浅色。
7. 情绪积木右键可指定旋律来源或移除此情绪段。移除由邻段填补，不缩短作品。旧局部覆盖可右键清除。
8. 编辑后自动更新下方拼接预览。拖动中按 Esc 取消，编辑区 Ctrl+Z 或“撤销”恢复。
9. 点击底部“生成连续成品”，再在右侧整曲/分块试听。右侧历史版本保留；新修改需重新生成才能听见。
10. 顶部保存/打开工程，右侧导出 WAV / MIDI / MMP。“仅主旋律”关闭伴奏与情绪配器。

## 分块与速度

素材从首音开始每四拍一块，尾部保留不足四拍的部分。每块时长为 240 / 作品 BPM 秒。
仅有默认素材时，首次导入替换它并采用新素材 BPM；后续追加沿用作品 BPM。
素材试听也按作品 BPM 播放。支持固定 4/4 拍、固定 40–220 BPM，不自动识别乐句或压平变速。
彩色情绪积木控制情绪安排，下方拼接预览显示实际旋律来源。

## 包内内容

- app：最新可编辑源码、测试与 Step1 / Step2 依赖。
- _internal / runtime：Python、Tk、NumPy 与 LMMS 本地运行组件。
- samples：随原包提供的素材和音频示例；licenses：第三方许可。
- docs/BLOCK-LOGIC.md：分块与旋律来源说明。
- docs/UI-UPDATE.md：本次界面变化。其余历史文档用于参考，以本说明为当前操作依据。
- self-test.txt：本次验证记录；MANIFEST-SHA256.json：本次发布文件的 SHA256 清单。

沿用原分发范围，不附带个人工程、试听历史、开发缓存和旧错误日志。
新工程及生成结果保存在 app/EmoBlocks 下。不要把运行目录放在不可写位置。

## 现有限制

这是离线规则 Demo。导入读取音符，不复现原乐器插件、音色效果与演奏控制。
默认取同起音高声部、多音轨中加权平均音高较高轨，不保证识别到真正主旋律。
未附带 Basic Pitch 大型依赖和模型；精细创作的音频转 MIDI 需另行配置。
文件拖入要求本程序与资源管理器权限级别一致，通常不要以管理员身份运行。
解压目录过长可能触发 Windows 音频路径限制，建议使用短路径。
默认旋律来源见 samples/DEFAULT-MELODY.md；第三方许可和 LMMS 许可均随包保留。
