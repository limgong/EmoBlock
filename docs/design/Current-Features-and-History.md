# EmoBlocks 音乐积木工作室

快速导入简化：选择一个或多个 MIDI/MMP 文件后立即加入素材，移除音轨白框、“加入素材”按钮及高低音选择框；拖入文件采用相同流程。默认同时起音取高音，多音轨按音符时长加权平均音高选择较高声部，并记录所选音轨提示（不保证是主旋律）。批量导入全部检查通过才提交，原文件不变。按钮改用与卡片协调的圆角深色描边，卡片内按钮使用紧凑边距，菜单／下拉框统一深色。

输入分块现以小卡片呈现：107×77，约为来源卡片 210×150 的宽高各除以 1.96，随窗口自动换行。显示块编号、拍数、时间范围和音符缩略图，跨块延续音另色标记。点击卡片试听并更新下方音符详情；卡片内按钮可播放／暂停／继续，到块尾停止。分块属于来源旋律，不单独提供用途设置或删除；这些操作仍在来源大卡片上进行。

素材卡片内操作：右上角用途文字现为下拉按钮，点击直接选择自动判断／主基调／副旋律／爆点／结尾；底部有独立播放／暂停／继续与删除按钮。点击这些按钮不会触发卡片背景的重新试听，用途修改不会重启音频。卡片外原播放、设置、删除按钮移除，选中素材的拖拽进度条继续保留。

成品进度条支持点击／拖拽定位：按下暂停当前试听，拖动显示目标时间及块高亮，松开从该位置继续播放所选历史成品。停止后也可直接拖动开始试听；分块试听时拖动会切换为该成品的整曲播放，不再停在原块尾。不会修改 WAV 或重新生成。

自动记忆点：简要创作默认在程度最高的情绪段放置一个“原旋律”记忆点（金色标注），平稳／渐弱段取开头一块，渐强段取末端最强一块，同强度取较早段。按四拍保持，末尾不足一块则截短；指定了旋律时用指定素材，否则优先主旋律角色、再取第一段输入。从原旋律开头呈现，不选变体／回答句／副旋律，不替换为连接，情绪配器仍保留。随情绪线修改重新计算；与手动记忆点或手动修改块重叠时让位，不覆盖手动设置。默认紧张为 50%，振奋为 85%，因此默认点在振奋段。重新生成生效，旧 WAV 不变。

情绪线长度：简要页情绪工具上方新增“＋ 加长 1 块”“− 缩短 1 块”，按 BPM 对应的四拍网格调整末尾。加长延续末尾情绪，缩短裁去末尾，不整体拉伸或移动已有段落，支持撤销；若会截掉固定记忆点或手动修改块则提示先处理。也可用原“作品秒数 / 应用时长”输入精确长度；当前范围仍为 4–480 秒。修改后重新生成，旧成品不变。

末尾收束更新：当振奋之后的最后一段为低强度平静时，自动生成“过渡＋结尾”块，不再直接切回普通平静主题。保留原拍数和振奋段，承接前句末音及音色，逐步降低力度，后半段退出节奏点缀并用主音长音收尾；多块结尾按整个结尾区间展开。固定记忆点和手动覆盖不被替换。此为规则生成，需重新生成成品，历史 WAV 不变。

默认情绪方案更新：新建简要创作采用 **1 格平静 → 2 格悬疑 → 3 格紧张 → 2 格悲伤 → 4 格振奋 → 1 格平静**，共 13 格，每格 4 拍。未修改该方案时，首次导入的 BPM 会带动整条方案换算时间（120 BPM 为 26 秒，65 BPM 为 48 秒），不是按秒数拉伸拍数。自定义工程/情绪线不在生成时重置；“恢复默认情绪段落”可显式恢复并撤销。

连接优先利用相邻悬疑段，使普通平静主题先正常表达。悬疑段可合并承担前后两个边界的衔接，不再额外占用旁边平静段。明确的非悬疑段开头一块保留主体，70% 以上强表达继续保护；连接空间不足用边界衔接，不要求每次情绪切换都新增 Bridge。悬疑只是优先候选，不保证任何输入都强制改写为过渡。

主体保护更新：明确强度 ≥70% 的块不再被替换为连接；其他块的强度越高，可占用连接长度越少。上升优先使用前侧低强度块铺垫，下降优先使用后侧低强度块收束，空间不足降级为边界衔接。固定记忆点与手动块覆盖保持保护。历史音频不会自动改变，请重启程序并重新生成。当前 Bridge 标签表示“多块旋律过渡”，不等同于已实现完整曲式桥段。

## 2026-09-22 源码新版：简要创作

块长规则修正：普通音乐块固定 **4 拍**（当前 4/4 拍的一小节），时长为 `4 × 60 / BPM` 秒，不按整曲秒数均分。120 BPM 为 2 秒，65 BPM 约 3.692 秒。情绪吸附、连接替换共用此网格；中等连接预算 4 拍，大落差预算 16 拍，多块 Bridge 至少 8 拍。严格秒数锚点与作品结尾可局部截断小节，但不重排后续拍网格；界面显示 BPM 与每块秒数。

当前交互修正：情绪线始终连续覆盖整首作品（默认平静），涂画自动吸附到完整音乐块，拖动情绪分界时相邻两段联动，不留缝隙；删除一段后相邻情绪补满。细竖线显示操作块网格。连接不是情绪线中的空位：系统根据类别/程度变化自动将既有时间内的内容块替换为过渡或多块 Bridge，预览底栏用金色显示替换区域。完整画满的情绪线同样可以生成连接，固定记忆点不因此后移。旧工程的部分情绪线在新页打开时自动补全并吸附，原文件不覆盖。

情绪输入已简化：点击六种情绪按钮 → 用“柔和—强烈”滑杆和“平稳／渐强／渐弱”设定表达 → 在线上拖出范围。重复涂画覆盖重叠部分；“整段应用”可一次设置全曲。切换“选择 / 移动”可选中、移动、更新或删除已有段；“固定爆点”模式点击时间位置即可添加记忆点（默认保持 2 秒，临近边界时缩短）。精确秒数、起止百分比、旋律指定和要求列表收在“精确设置”中，默认不展开。所有修改可撤销，固定记忆点仍优先于普通情绪线。

1. 选择 MIDI/MMP 文件与旋律音轨，点击“加入素材”。可输入短灵感或多段主题，角色可保持自动。

3. 重要位置用“固定记忆点秒 + 保持秒”，选好情绪、起始程度及可选旋律，添加锚点。重叠锚点会报错；锚点优先于普通曲线。

## 3. 全部已实现功能

### 3.1 单窗口与两种模式

- 快速成品：旋律加情绪线，自动完成素材发展、结构、编配、连接和音频输出。
- 精细创作：同一窗口中的“素材”“结构”“情绪与连接”三个页签。
- 两种模式共用项目，快速成品可直接转入精修；不打开独立播放器或 LMMS 创作窗口。系统文件选择／保存对话框仍保留。
- 页面可滚动，底部显示任务进度／错误；生成期间禁用编辑，停止播放仍可使用。

### 3.2 旋律输入与多段输入

- 支持用本机 Basic Pitch 0.4.0 导入 WAV、MP3、OGG、FLAC、M4A；在界面填写音频 BPM 后，后台生成 MIDI，再进入原有的轨道与小节选择流程。最适合单一乐器、旋律清晰的录音。
- 转写完全在本机运行；生成 MIDI 与 `source.json` 来源记录保存在 `audio_imports`，不会覆盖旧结果。独立运行环境默认位于项目根目录 `work/basic-pitch-venv`，依赖清单为 `requirements-basic-pitch.txt`。
- 支持 MIDI type 0/1、未压缩 LMMS MMP，选择旋律轨、起始小节和范围。
- 支持不同文件逐段导入，也支持同一文件多个小节选区；加入列表时保存音符副本。
- 快速列表可上下调整顺序、移除素材，确认生成后按顺序使用，不自动打乱主题。
- 固定 4/4，40～220 BPM；每块 4～8 小节，快速模式最多 6 块，同池统一 BPM 和调性参考。全曲最多 128 小节。
- 同时起音默认拒绝；可明确选择保留高音或低音，并选择截短重叠尾音。记录删减与裁切，不宣称自动提取了主旋律。
- “使用你的平静版”可加载附带 MMP；其中有同时起音，需明确选择整理策略。

如需重建独立转写环境，请在本目录使用 Python 3.9～3.11 执行：

```powershell
python -m venv ..\..\work\basic-pitch-venv
..\..\work\basic-pitch-venv\Scripts\python.exe -m pip install -r requirements-basic-pitch.txt
```

### 3.3 原主题、变体与关联回答句

- 素材池管理原主题 A/B/C、同来源内容变体和关联回答句 E/F/G。
- 规则生成局部模进、节奏变化、句尾变化与单参考回答句；可换种子生成候选、中性音色试听、保留候选并查看来源。
- 保存素材 ID、父来源、参数与版本；候选不足会提示，不以原曲复制冒充新素材。
- 单参考快速模式生成 1～6 段：原主题加自动选择的回答句。多输入模式直接保序使用全部给定主题，不自动补回答句；可到精细页继续发展。

### 3.4 固定结构与许可插入

- 确认前可调整原主题顺序；确认后骨架保序、不可省略或重复，不自动改成 A→C→D→B。
- 同源变体可原位替换／还原；B 的变体不能替换 C。
- 回答句默认允许在来源主题后插入，其他骨架位置需明确授权；授权只表示结构许可，不保证音乐相容性。
- 支持段落角色、移除关联插入项、撤销、结构时长与展开列表。

### 3.5 六情绪与自动编配

六种表达：平静／安定、温暖／希望、悲伤／失落、悬疑／不安、紧张／危机、振奋／坚定。“高潮”是发展与强度目标，不单设第七种情绪。

规则自动处理和弦、低音、铺底、琶音／脉冲、鼓、配器、声部层次、力度及基础空间效果。素材阶段可产生有限内容变体；连续作品路径保留所选主旋律的音高、起音和时长。合成音色不等于真实乐器录音。

### 3.6 跨块情绪线与强度

- 对一个或连续多个块设置情绪、起止强度；按实际小节长度分配变化。
- 支持拖动整块强度端点、查看颜色与折线。
- 快速模式的曲线是下一次创作模板；精细模式修改当前作品。修改模板不会暗中改掉已有作品。
- 完整生成会统一规划整曲；要保留其他编配，应使用局部修改流程。

### 3.7 块内小节级情绪变化

在情绪页下方“块内情绪”选择块、起止小节、情绪及强度并应用，可多次设置，例如前两小节平静、后两小节紧张。不拆块、不增加时长；未选小节的设置保留。

界面显示逐小节色带、强度和标签；编配按小节采样，播放显示当前小节与情绪。支持撤销、保存重开、完整／局部生成，独立过门也适用。

### 3.8 拍级节点与更细情绪线

- 使用上方选中的块，在“更细的情绪线”输入拍号、情绪和强度，添加／更新节点；点图可先选拍与强度，再提交。
- 同一拍提交即更新，内部节点可删除，首尾节点只能修改。整数拍网格，不支持拍内小数位置。
- 4 小节块的播放拍为 1～16，编号 17 是终点，只影响收尾强度，不新增时长。
- 强度在节点间线性插值，情绪类别从节点处切换到下一节点；不是两种情绪连续混合。
- 实际编配逐拍采样强度中点，控制配器、力度及节奏密度；和弦仍逐小节规划。持续主旋律不因节点被切断。
- 播放显示当前拍、情绪与目标强度；强度显示不是实际响度测量。
- 小节细分和拍级节点互斥，切换前需用整块应用明确重置。整块应用／端点拖动会覆盖细分，支持撤销。

### 3.9 边界连接处理

读取实际相邻音符、和弦和能量，处理末拍低音导向、节奏引入／撤出、首拍伴奏柔化及共同音延留。情绪类别在块内切换时也可应用连接处理。

连接开关用于对照；这些操作发生在既有时间内，不额外增加小节。音符统一放入整曲时间线，一次渲染，不拼接各块带尾音的 WAV。

### 3.10 独立过渡块

结构页在“当前展开”中选择前一块 → 选择 1／2 小节 → “在选中块后生成”。过门显示为 `T(A → B)`，绑定实际两端，由句尾、起音和调性参考规则生成，不当作任意复用的回答句。

新增过门增加总时长，后续顺延，不占用原块。默认强度承接两侧、情绪取后块，可独立编辑。支持移除、撤销、保存、完整导出和播放单独高亮。关闭边界连接不会删除过门。

禁止首尾孤立过门或两个过门相邻；破坏两端相邻关系的编辑会提示先移除过门。插入／移除后须完整生成新基准，再继续局部修改。

### 3.11 局部修改、保留与撤回

1. 右侧选择历史成品作为基准。
2. 在精细页修改并应用目标块情绪，包括小节细分或拍级节点。
3. “① 预览局部影响”显示目标块、边界块、实际小节范围和保留事件数。
4. “② 生成局部修改”另存新版本，范围外音符和声部设置原样复用。
5. 选择局部结果，点击“撤回局部结果”恢复基准结构／情绪并选中旧成品。新文件不删除，普通撤销也可撤销此次恢复。

须保持结构、素材、速度、长度和连接开关一致，否则要求完整生成新基准。默认目标整块与相邻边界各一小节可更新；跨范围延音会扩展范围并提前显示。即使只改一个拍，当前仍按整块规划影响，不承诺保留该块其他小节伴奏。

基准依赖保存的结构、音符和报告，支持链式局部修改。预览后参数或基准变化须重新预览；缺失／损坏基准报错，不静默全曲重编。音频仍整段渲染，音源尾音、回声及全局峰值保护可能影响其他采样；不保证混音逐采样不变或渲染提速。

### 3.12 播放、历史与导出

- 内置素材试听、成品播放／停止；显示设备进度、总时长、当前块和分块高亮，过门也单独显示。
- 有细分设置时显示小节／拍及情绪，拍级显示插值目标强度；尾音、结束和停止独立处理。
- 时间表来自选中结果的生成快照，不拿当前编辑结构解释旧音频。
- 历史结果可切换试听；改参数不会自动改变旧音频，须生成新版本。
- 导出连续 WAV、多轨 MIDI、可编辑 LMMS MMP。结果目录还保存结构、音符事件、处理报告和渲染日志；MIDI 不包含合成音色。
- 原曲与旧输出不覆盖；成品仅末尾另加 1 秒效果尾音。

### 3.13 项目保存与恢复

另存完整工作台 JSON：素材池、固定结构、过门、情绪设置／节点、快速模板、输入列表及结果索引；兼容已有素材池和结构 JSON。新建、重新快速创作与关闭前自动保存需要保留的项目；失败提示，不直接丢弃。

结果音频与局部基准仍以路径引用，尚不是自包含工程归档。搬到另一台电脑仅带 JSON 不够：须保留对应资源与路径或重新完整生成。MMP 也可能引用生成机器的包内鼓样本绝对路径，跨位置编辑建议重新导出；WAV 试听不依赖这些路径。
