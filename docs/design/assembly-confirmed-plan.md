# 分块素材与情绪积木改版确认稿

## 1. 整体目标

创作流程调整为：

**导入旋律 → 直接操作分块素材 → 拖拽组装积木条 → 整块涂色情绪 → 编辑强度线 → 预览与生成。**

重点改变素材的组织方式、积木的组装方式和二维预览。保留现有自动变奏、连接、情绪配器、试听、版本历史、保存和导出功能。

界面继续使用原有浅色/深色主题、情绪配色、字体、圆角、阴影及拖动动画。参考图片用于确定空白拖放区的结构，颜色随现有主题变化。

## 2. 素材区：分块成为主要操作对象

### 分块展示

- 主界面直接展示分块卡片，包含名称、来源、拍数、简要音符预览和试听按钮。
- 原始完整旋律作为来源分组，完整旋律的查看、试听和用途设置收进次要入口。
- 保留现有每 **4 拍**切分，以及末尾不足 4 拍的短块；本轮不增加自由裁切。
- 单击卡片负责选择，拖动负责组装，播放按钮负责试听。

### 组合素材

支持跨旋律、非连续选块、自由排序和重复使用。例如：

`A2 → B1 → A2` 保存为 `组合素材 C`

提供两个入口：

1. **素材区的组合编辑窗**：加入分块、排序、移除、试听、命名并保存。
2. **积木条另存**：选择连续多个积木，通过“另存为组合素材”保存其旋律组成。

两个入口保存的都是旋律组成与顺序，不携带当前作品中的情绪和强度设置。

组合素材：

- 作为一个独立素材保存，可再次参与组合。
- 卡片带有“组合”标识，并简要展示组成，例如 `A2＋B1＋A2`。
- 详情可以追溯原始旋律、分块和排列顺序。
- 拖入组装区后是**一个整体积木**，统一涂色；查看内部组成不会自动拆开它。
- 保留音符快照，原始文件移动后仍可使用。

本轮保留后续分块改写所需的身份与来源信息，模型接入和改写操作另行实现。

## 3. 积木区：用户组装，情绪和强度分别编辑

### 空白状态与组装

新建工程的组装区为空，展示圆角虚线拖放区：

> **拖入旋律分块，搭建你的情绪积木**  
> 自由排列顺序，再为每块添加情绪与强度

素材区仍可提供现有示例旋律的分块。

- 拖入素材创建一次独立使用，素材区中的原素材继续保留。
- 支持追加、插入、重复使用、换序和删除。
- 拖动显示插入位置；拖出有效区域或按 Esc 取消。
- 删除后后面的积木向前紧接；作品长度由所放素材的拍数累加得到。
- 同一素材使用两次时，两次可分别设置情绪。
- 新积木默认“平静”；涂色作用于完整积木，相邻同色情绪也不合并素材身份。
- 新组装方式不再通过“增加/减少空白四拍块”决定作品内容。

### 编辑条、强度线、二维预览分开

延续现有三个区域的职责：

| 区域 | 操作与作用 |
|---|---|
| 上方积木条 | 拖入、选择、排序、删除、整块涂色、另存组合素材 |
| 强度线 | 继续编辑整曲连续强度变化 |
| 下方二维预览 | 展示各积木的顺序、时长、情绪和强度位置 |

二维预览采用以下规则：

- **横轴**：按组装顺序从左到右排列，宽度与音乐时长成比例，同时标注积木序号。
- **纵轴**：表示强度，范围为 0%–100%。
- **积木形态**：保持水平和固定厚度，以积木中间时刻的强度决定其中心高度。
- **颜色**：表示该积木的情绪。
- **曲线**：完整显示；长积木内部的声音仍随连续强度变化，不简化为一个固定强度。
- **预览单位**：与用户组装的积木对应。组合素材保留一个外框，组成及自动连接信息放在内部标记或详情中。
- 编辑条、强度线和预览使用一致的横向比例与滚动位置。

例如：

`A1〔4 拍〕 → C〔8 拍〕 → A3〔4 拍〕`

预览仍显示三个积木，宽度比例为 **1∶2∶1**，各自位于强度线对应的高度。

### 移动与强度的关系

移动积木时，**素材和情绪一起移动，强度线保留在原时间位置**。移动后的积木读取新位置的强度，因此预览高度可能改变。

追加时，新增时间段默认延续末端强度；删除导致总时长缩短时，保留剩余时间范围内的曲线。以上操作均可撤销。

## 4. 生成、保存与兼容约束

- 用户确定素材顺序及各积木占用时长；生成器继续使用现有自动变奏、连接和情绪配器能力。
- 自动处理不能擅自调整用户的积木顺序或增加作品总时长。变奏、连接结果保留与所属积木的对应关系。
- 现有自动记忆点继续工作，并关联峰值所在的积木及其来源。
- 素材按工程 BPM 使用，沿用现有统一速度的规则。
- 每个素材有独立身份、音符快照和组成记录；积木条上的每次使用另有独立身份和情绪设置。
- 组装顺序、组合来源和强度线纳入工程保存、撤销重做、生成快照及版本差异判断。
- 组合编辑窗内的操作先作为草稿；保存后一次性加入素材库，取消不修改工程。
- **旧工程保留原编辑与生成方式，新建工程采用新组装方式。** 不自动转换或覆盖旧工程。
- 通用实现继续由 Mac/Windows 共用，保持现有平台适配接口。

## 5. 验收标准

1. 导入旋律后，主界面可直接找到并试听分块，无须先打开分块详情窗。
2. 两个入口都能保存 `A2 → B1 → A2`，重新打开工程后组成关系仍准确。
3. 同一素材重复拖入可独立涂色；组合素材整体涂色、移动和删除。
4. 插入、换序、删除、取消拖动、撤销和重做均保持正确的素材顺序、时长及来源。
5. 二维预览满足时长比例、强度坐标和中点定位规则；移动积木不带走强度线。
6. 生成结果保留现有变奏与情绪处理，来源能够对应用户组装的积木。
7. 空组装区显示占位提示并禁用生成；短尾块、休止块和长组合素材能够正确呈现。
8. 保存、重开、试听、历史版本和三种格式导出通过回归检查；旧工程继续正常使用。
9. 检查浅色/深色主题、小窗口、Mac 触控板和 Windows 鼠标操作，并运行现有完整测试与双平台接口检查。
