# 强度画布工作流 v2：已确认产品约定

状态：产品约定已确认；本次仅 BOOTSTRAP，不实现以下功能。后端内层新格式为 `emoblocks.assembly.v2`，接口草案见 [契约](curve-workflow-contracts.md)，协作见 [团队协议](curve-workflow-team.md)。

本文是本轮产品依据。`assembly-confirmed-plan.md` 是旧 v1 方案；与本文冲突的水平组装条、自动压缩时间轴、情绪画笔、生成隐式选材等要求不得重新引入。现有代码仅作为开发基线，不能把现有行为当作 v2 已实现。

## 1. 三栏主界面与旧工程

左栏显示完整旋律及其版本，可折叠；中栏显示分块素材，纵向滚动；右栏只有一个二维强度画布，底部共用播放器。撤下“精细创作”入口。旧工程先保留读取和已有成品试听、导出，不做完整编辑迁移，不自动把旧作品改写为 v2。

## 2. 导入与四种完整旋律

导入 MIDI/MMP 后，提前准备：A 原始；B 修改后半段部分音高并调内调整；C 反转轮廓并调内调整的回答句；D 调整音高、缩短时值的副旋律版本。D 替换当前旋律，不额外叠加声部。

各版本按四拍分块，末尾保留实际长度，编号 A1、A2、B1……。多次导入继续分配稳定编号，内部身份不依赖显示名称。

## 3. 快照、来源与明确试听

所有素材保留音符快照和完整来源。点击只选择，明确点击播放才试听。完整素材、分块、组合草稿、情绪变体、推荐和成品共用底部播放器，不另开试听窗口。播放器明确显示当前播放对象；试听不修改工程。

## 4. 分块卡片与行内组合

中栏素材卡尺寸一致，组合素材不靠长度区分。拖到目标卡左侧表示在前，右侧表示在后。拖放产生行内组合草稿，确认后新增素材，取消不修改工程。

支持重复使用与嵌套组合，原素材不被删除。组合保留一个外框、一个情绪，展示组成与实际拍数；来源与内部子片段仍可追溯。

## 5. 固定拍格、直接二维放置

强度线主导：先设置 N 个四拍格，总长度固定，默认 8 格、120 BPM，不自动填入素材。先编辑或手绘强度线，再直接把素材放到二维画布上；取消独立水平组装条。

起点每拍吸附，素材占用实际长度，不隐式拉伸或裁切。移动和删除不压缩时间轴；重叠、越界应拒绝。改变 BPM 保持拍位置；缩短长度不得隐式截断已有内容。

## 6. 强度与积木几何

积木宽度对应时长、厚度固定，中心高度读取其中点时刻的强度。移动积木不带走强度线。

保留控制点编辑，增加手绘轨迹转控制点；手绘结束只提交一次撤销记录。画布绘制、命中、拖动、吸附和滚动采用一致坐标规则。

## 7. 行内情绪与基础素材保护

点击积木后出现行内情绪选项，取消涂色情绪画笔。新放置默认平静。

情绪处理允许轻度旋律变化与编配变化，保持动机辨识度和时长。每次从该次放置的基础素材快照重新计算，不能累计失真；不能改变素材库原件或其他同名素材的使用。

用户明确选中 B2 后，生成阶段不得隐式轮换成其他版本。

## 8. 自动峰值记忆

保留自动峰值记忆。峰值落在 B2 时，保护情绪处理前的 B2 音高和节奏，不恢复 A2；允许情绪编配。

沿用峰值所在四拍片段的保护，组合内定位对应子片段。峰值为空缺时显示待落位；峰值在主动留白内时不得强行填入主旋律。

## 9. 待补全与主动留白

区分待补全空缺和主动留白。主动留白禁止填入主旋律，允许克制的伴奏延续和自然尾音。素材自身的休止属于该素材快照，不因补全操作被改写。

## 10. 五类连接与自主决策

连接是核心算法。首批类型：自然延续、动机回应、渐进铺垫、留白进入、回落收束。先实现各类实际音乐处理，再实现自主选择。

根据相邻素材关系、情绪与强度趋势、可用时间判断连接。允许替换较大片段，但保护记忆区、主题、乐句和主动留白；不移动素材、不延长作品。不需要专门过渡也是有效结果；没有窗口时轻量衔接。

不使用主副歌标签，鼓组填充不能成为默认处理。保存选择原因、影响范围和原始拼接快照，支持对比试听。

## 11. 自动补全与推荐

同时提供自动补全和查看建议。自动补全只修改待补全区域，一次撤销可恢复。

推荐至少两套有实际音乐差异的有效方案，考虑左右衔接和整体重复程度。选中空缺时针对该处，否则针对全部空缺。试听不修改工程，确认后才应用。不足两套有效方案时明确说明，不能伪造。

未解决空缺时，生成入口提示补全、推荐或标为留白，不隐式处理。

## 12. 编配、输出与仅主旋律

保留现有整曲编配、MIDI/MMP 输出、LMMS 连续 WAV 渲染及尾音处理。“仅主旋律”关闭伴奏，使用统一音色和力度，但保留已规划旋律和连接。

## 13. 保存、撤销与异步快照

保存、撤销、生成快照、版本差异判断覆盖全部新状态。后台结果绑定输入快照和版本，过期结果不能覆盖当前编辑。播放对象、当前编辑、选中成品版本必须明确区分。

沿用已完成的 busy、阶段提示、失败恢复、工程快照保存与安全导出能力；保存不是生成，生成成功不自动播放或导出。失败保留当前编辑、历史及已有文件。

## 14. 双主题、双平台与布局

继续 Python/Tk、共享前端及 Mac/Windows 配对适配器。明亮模式为 Soft UI；黑暗模式为静态 macOS Vibrancy：`#1c1c1e`、`#2c2c2e`、`#3a3a3c`，1px 边框，最大 12px 圆角，`#0a84ff` 作为交互强调，无渐变、发光或装饰性动画。

情绪积木颜色为明确例外，文字对比度满足 AA。不实现原生毛玻璃，不改 Web 技术栈。最小窗口 1020×700，窄窗口优先收起来源栏。简短标签常驻，说明使用悬停和焦点提示；错误与关键状态直接显示。

## 15. 接口预留与验证边界

哼唱输入、外部模型分块变体只预留接口，本轮不安装或接入模型。

自动测试不能替代实际音乐听感与 Mac/Windows 实机验收。必须区分自动测试、程序化 Tk、实际 LMMS 渲染、实际设备播放、人工视觉/听感及 Windows 实机。未执行的项目明确待验，不把模拟验证报告为实测。
