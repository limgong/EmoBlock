## 布局

Python/Tk shared三栏：1280×800来源约180px、中栏252px、间距8px、右栏剩余；最小1020×700，<1180默认折叠来源但尊重用户刚执行的展开/收起。单行约48px顶栏含品牌/项目/保存/文件菜单/undo-redo/theme，关键错误直接可见。来源与素材独立纵滚，单一画布横滚；无整页横溢。
来源标题旁导入、全部素材入口、来源筛选/简述/一个明确试听动作；选择来源不自动播放、不弹出常驻大段细节。新旋律仅中栏。素材卡约96px/间距8px、虚拟化、原稳定编号在短名之前、实际拍数/真实音符图/小试听按钮；组合与普通同尺寸，整句展开四拍子块，完整名称/来源/方法用详情和真正hover/focus提示。
右栏单一二维画布在编辑与候选状态有效高度>=320px；候选审阅在其下，不占中栏。不相关编辑工具收起。底部共用播放器约72px只在第三栏，含对象/模式/时间进度/播放暂停/停止/格式导出。真实音频可用才可画真实波形；否则普通进度。路径/ID/日志进入详情，导出简短结果+打开文件夹。
禁止恢复独立组装条、重复强度图与二维预览、右栏BPM、情绪画笔、固定ABCD族。

## 工作流

空工程显示“导入旋律，开始创作”及导入；导入不填画布。卡片点击仅选，明确试听才播放意图。卡片左右组合草稿，只有草稿时显示“确认组合/取消”；取消不改工程，确认新素材保原件/来源。
确定总格数→强度→放素材。三个明确模式“编排/控制点/手绘”；拖入转编排避免误加点。仅选积木显示情绪，仅选gap显示“生成此处方案/设为留白”。情绪仅该使用实例，从基础计算。移动/删除不压时间、不带走强度；重叠/越界/缩短截断原子拒绝并简短说明。横轴拍和四拍格、纵轴强度百分比，tick与阶段码仅详情。
记忆是准确范围上的短“记忆”叠放标识而非圆点；组合定位子片段，空缺待落位/主动留白不填。bridge/连接块/最终边界真实计划范围各自可分，视觉热区不改变音乐范围。
主入口“生成方案”=现有完整推荐仅预览；选gap局部，否则全部/无gap当前排列。严格后端顺序补全→bridge决策与同事务锁→bridge生成认证READY→连接块→最终边界→编配渲染。不得因界面文案把锁移到生成后。已有保护/来源/时长/留白/局部输出门禁不变。生成时仅真实阶段/耗时/取消/可展开详情，不伪进度。
审阅含候选选择/模式/原始拼接与处理后对比试听/“采用方案”/“返回编辑”，选择及成功不自动播/应用，不足两套真实原因。高级入口保留分阶段/手工bridge/“自动补全并应用”(次级明确标签，原同管线事务)，往返保草稿/预览状态不隐式应用。
合并“准备→播放”为明确一次“试听”：有效缓存立即播，否则后台准备并在同一有效前端临时意图下播放。意图至少绑定kind/id/mode/input snapshot/requestID；stop/cancel/选择变化/音乐编辑/新试听均失效。旧结果允许原缓存规则但不得抢播；仍重检音频就绪/版本/mode/文件。来源/块/组合草稿/情绪/推荐/历史均共用播放器。播放对象、编辑、候选/成品选择、导出目标分开。
采用同快照一次事务/一次undo；返回不采用；视图切换不影响音乐dirty/undo/草稿；保存重开身份保持；格式菜单逐格式availability与同score/mode/版本绑定。
