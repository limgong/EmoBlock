# 旧视觉恢复：用户复核表

本轮保留 r3 三栏、固定时间轴、唯一强度画布及第三栏共用播放器。技术检查、用户视觉接受、物理输入、设备播放和音乐听感分别记录。静态 Vibrancy 风格不含原生背景模糊；素材类型色和情绪数据色是已确认例外。

在本轮已验收工作目录运行 `run.py`，使用已有项目解释器；测试工程、导出和输入副本放独立目录。不要覆盖真实工程。最终报告提供确切提交、启动目录和证据索引。复核前记录代码提交、操作系统、Python/Tk、屏幕缩放、窗口尺寸与音频设备。

## Mac 约五分钟视觉与交互复核

1. 打开空工程，切换明亮与黑暗主题。检查积木品牌、太阳/月亮、保存状态及底部空播放器。来源栏展开/收起；主题和布局变化不能产生未保存状态或撤销记录。
2. 分别调整至 1020×700、1280×800、1440×900（记录客户区和含系统标题栏尺寸）。关键操作可达，窄窗口可以收起来源；右栏没有 BPM、情绪画笔或第二条时间轴。
3. 导入一个 MIDI 和一个 MMP 输入副本。检查稳定编号、统一卡片高度、真实音符缩略图和类型标识；长名称可通过焦点/悬停查看。点击卡片只选择，明确试听才播放，不自动放入画布。
4. 拖素材到另一卡左右两侧，分别检查前插/后插提示。取消组合不入库；确认保留原件。将普通块、短尾、整句和组合拖入画布，检查浮块、真实吸附范围、重叠/越界拒绝；Esc 和外部释放完整取消。
5. 检查积木仅显示编号与情绪，旋律线段留在内部并保留休止。选择/播放/保护不改情绪填色。组合内记忆徽标准确；排列时控制点隐藏，控制点/手绘模式可编辑；移动积木不带走强度线。
6. 点击长度加/减：每次四拍，可撤销；缩短会截断积木、留白、保护或内部控制点时必须拒绝。滚动后再次拖放和编辑控制点，命中位置应准确。
7. 使用真实完整推荐，明确对比原始拼接与处理后结果。不足两套如实说明；点击候选不播放。Bridge 先锁再生成，后续连接不覆盖；局部方案保持未完成和正式导出限制。
8. 在底部播放器检查真实波形、暂停/继续、定位、停止、上一块/下一块及块导航。选择另一素材/版本时，正在播放对象的波形、时间和导航保持原对象，直到明确试听切换；无可信映射时说明并禁用导航。
9. 采用方案，一次撤销恢复；重做不重新生成。保存快照、重新打开，编号、来源、编排和版本保持。明确选中成品逐格式导出 MIDI/MMP/WAV，核对目标版本与模式；某格式缺失不禁用其他有效格式。
10. 用触控板、物理鼠标和键盘分别测试：嵌套竖向滚动、画布横向滚动、细滑块拖动、Tab 焦点与提示、Space/Return 图标激活、Delete/Backspace、Command 撤销重做和 Esc。滑块空闲隐藏，无布局跳动；焦点/拖动期间不能隐藏。

界面状态另检查默认、悬停、按下、焦点、禁用、选中、播放、忙碌和失败。人工操作必须留实际截图或简短录像，不能把程序派发事件记作物理输入通过。

## Windows partner

在实际 Windows 机器使用本地已验收源码和既有依赖，不复制 Mac 专属资源路径。分别在 100%／125%／150% 系统缩放运行上述步骤，尤其检查中文/衬线回退、下拉菜单与暗色滚动条、Ctrl 快捷键、Delete、鼠标滚轮/横向滚动、拖放和取消。检查 Unicode/空格目录保存、重开和逐格式导出；MMP 在目标 LMMS 中实际打开并核对资源。缺软件、设备或资源时记录 NOT_TESTED/BLOCKED，不放宽认证。

## 听感及反馈格式

使用保留的固定 Bridge 对照集，区分原始拼接、旧定位、新定位，以及正式方案的原始/处理后、仅主旋律/完整编配。记录模式、样例 ID、音频时间位置、动机辨识、突兀连接、休止、记忆保留、异常断音/杂音/尾音。真实渲染或设备流成功不能代填主观听感 PASS。
