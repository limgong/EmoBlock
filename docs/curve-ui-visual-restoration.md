## 最小只读公共增量

冻结接口见 `docs/design/curve-ui-playback-contract.md`。独立契约 ROUND1 发现高亮身份缺定义，ROUND2 PASS 后冻结。新增 `recommendation_playback`、`history_playback` 只读认证指定实际乐谱、模式、侧与音频；comparison 为捕获的顶层原始放置导航，不伪造嵌套演奏证明。缺映射的旧历史仍可播音频，导航明确禁用。

画布高亮须匹配完整 ScoreRef、side/mode、实际 notes/ticks/BPM 和真实归属；同一个基底 Project 指纹不足以证明处理后音乐一致。中性素材则保留捕获快照、BPM和音频身份，不从后来选择的素材或当前编辑推测。

`preview_edit` 在副本上执行正式 model.edit 和官方重算，返回允许/拒绝，不提交工程。释放时仍重新正式 edit；纯预览不授予提交权限，不解除锁。无新音乐 schema、任务框架或生成规则。显式非法模式不能作为省略参数回退。

新增 7 项服务行为测试覆盖两种准备好的模式及两侧谱面、历史与后来编辑隔离、返回副本、纯认证不作曲、文件缺失、非法模式、旧历史无映射、预览不改变请求/保存/历史及重算拒绝。局部初次测试夹具传错 AUDITION 参数失败日志保留，修正前置后通过；没有放宽产品门禁。旧真实 P7 成品副本通过新 getter 验证，属于历史真实资产再认证，不冒充新渲染。
